# Studio tutorial video

Record the English Studio tutorial with a real test account, Bot, and PixelMug. The target duration is **2 minutes 40 seconds** and the recommended project is `getting-started/03-ble-play`, because it demonstrates Bot, WebApp, and MPY in one flow.

The production package in this directory contains:

- `README.md` — shot list, English narration, recording checklist, and export settings.
- `pixelmug-studio-first-run.en.vtt` — ready-to-import English subtitles.

Use only real Studio UI captures. Mask token values, account names, device serial numbers, private LAN addresses, and unrelated logs before export. Keep the numbered click overlays consistent with the [Studio screenshot capture list](../capture-list).
