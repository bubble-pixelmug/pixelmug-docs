# 04 · 体验更多 MPY 应用

上一例通过手机控制水杯上的光点。这一次，我们让 MPY 在水杯上独立运行，体验实时行情、图片动画、音乐频谱和运动交互。你只需切换文件、安装程序，就能看到同一只 PixelMug 展现不同的能力。

本例仅支持 **PixelMug S1 系列（Pro / Lite），不支持 P1**。项目位置：`getting-started/04-more-mpy`。不需要 WebApp，也不需要连接手机蓝牙。

## 一、在 Studio 中体验

### 1. 选择应用

停止之前运行的智能体，在 Studio 中打开整个 `getting-started/04-more-mpy` 文件夹。

确认 Bot 入口为 `bot/index.js`，填写 Bot token。选择应用和配置 token 的方法与[第一篇](/getting-started/01-chat)相同。

本项目有两个放置设备程序的目录：

| 目录 | 用途 |
| --- | --- |
| `exampleMPY/` | 保存各个独立示例，供你选择和复制 |
| `mpy/` | 存放本次实际安装到水杯上的程序 |

Studio 每次加载的是 **`mpy/` 中的内容**，不会同时安装 `exampleMPY/` 里的所有应用。随项目替换 `mpy/`，将运行你当前放入的程序。

### 2. 关闭自动运行，启动智能体

在“运行配置”中**取消勾选“启动后自动运行设备代码”**，然后点击“启动智能体”。

与第三篇不同，本例通过 Bot 命令手动安装 MPY，方便你每次换好文件后再开始运行。安装期间保持 Studio 和智能体运行，水杯在线，电脑与水杯处于同一局域网。

### 3. 关联设备

在冒泡 App 中打开 Bot 私聊：

- 发送 `/help` 查看简要说明。
- 发送 `/bindPixelMug`，关联一台 PixelMug S1；也可以在 Studio 的“关联设备”卡片中完成。

如果已经关联了正确的设备，可以直接继续。

### 4. 安装并体验

发送 `/installMPY`。Studio 会把当前 `mpy/` 中的程序和资源加载到水杯上。

等待 Bot 提示 **“MPY 已在 PixelMug 上运行，可以开始体验了。”**，然后观察水杯。安装过程中收到“安装请求已接受”时，继续等待即可。

首次使用默认的 `bitCoin` 示例时，水杯会连接行情服务，然后显示 BTC/USD 价格。设备的 Wi-Fi 需要能够访问该行情服务。

## 二、如何切换应用

四个示例共用同一个 Bot，切换时不需要更换 token，也不需要打开另一份 Studio 项目。

1. 在 Studio 中停止智能体。
2. 清空项目 **`mpy/` 内的旧文件和子目录**；如果修改过并希望保留，先备份。
3. 从 `exampleMPY/` 中选择一个示例，把该文件夹内的**全部文件和子目录**复制到 `mpy/`。
4. 保持自动运行选项关闭，重新启动智能体。
5. 在冒泡 App 中发送 `/installMPY`，等待运行成功后体验新应用。

例如，切换到音乐播放器后，目录应为：

```text
04-more-mpy/
├─ bot/
├─ exampleMPY/         保留各个示例原件
└─ mpy/
   ├─ __main__.py
   ├─ mps.json
   ├─ ogg.py
   ├─ spectrum.py
   └─ test_audio.ogg
```

::: tip 复制文件夹里面的内容
入口应为 `mpy/__main__.py`，不要复制成 `mpy/musicPlayer/__main__.py`。除了 Python 文件，也要一起复制 `mps.json`、图片、音频等资源。
:::

## 三、四个应用分别可以体验什么

### bitCoin：把实时行情放到水杯上

**复制来源：`exampleMPY/bitCoin/`**

水杯直接通过 Wi-Fi 获取 Kraken 的公开 BTC/USD 行情，并用绿色数字显示价格。无需填写行情账号或 API Key。

启动时先显示 `CONNECT`，随后显示 `WAIT`，收到行情后显示以美元计价的价格，之后随行情更新。这个示例展示设备自己访问网络并持续更新屏幕的能力，无需手机页面参与。

### rotateImage：旋转图片动画

**复制来源：`exampleMPY/rotateImage/`**

运行后，水杯会显示持续旋转的图片图块。素材是一张 32×16 的 `asset.png`：右半部分铺成背景，左半部分在屏幕中央顺时针旋转。

无需额外操作，安装后即可观看。切换时记得把 `asset.png` 一起复制到 `mpy/`。

### musicPlayer：点击播放，观看音乐频谱

**复制来源：`exampleMPY/musicPlayer/`**

运行后，屏幕滚动显示 `Click to Start`，底部跳动的红色倒三角指向触摸按键。

1. 单击水杯底部触摸按键，开始播放本地的 `test_audio.ogg`。
2. 播放时，屏幕显示随音乐变化的彩色柱形频谱和白色峰值线。
3. 播放结束后，屏幕显示 `Click to Restart`，红色倒三角再次出现。
4. 再次单击，从头播放，可以反复体验。

播放中的点击不会重新开始。音乐来自项目内的音频文件，不需要在线音乐服务。

### motion：摇动水杯，让粒子柱倒塌

**复制来源：`exampleMPY/motion/`**

屏幕底部中央出现一根宽 5、高 10 的白色粒子柱，由 50 个单像素小球组成。

倾斜或轻轻摇动水杯，粒子会随动作倾倒、散开，在屏幕中弹跳，并在边界反弹。画面中没有障碍物，可以直接观察水杯动作如何影响粒子运动。

**单击底部触摸按键即可重新开始**：所有粒子恢复为底部的白色柱子，速度清零，不显示额外提示。

这四个示例分别展示了网络、图像、音频和运动交互。保持同一套硬件和 Bot，只替换设备上的 MPY 程序，就能让水杯完成不同的任务。
